1. はじめに

本サービス「幻想郷ジェネレーター」（以下「本サービス」）は、上海アリス幻樂団様による「東方Project」の二次創作ツールです。 開発者は、本サービスを通じてユーザーに娯楽を提供することを目的としています。

2. 生成コンテンツについて

本サービスは Google Gemini API を使用して対話および物語を生成しています。以下の点にご注意ください。

  • 生成される内容はAIによる推論であり、東方Projectの公式設定や開発者の意図を必ずしも反映するものではありません。
  • AIの性質上、事実と異なる内容や、不正確・不適切な表現が含まれる可能性があります。
  • 出力結果により生じた一切のトラブルについて、本サービス側は責任を負いかねます。

3. 免責事項

本サービスは現状有姿で提供されるものであり、いかなる保証も行いません。 システムの不具合、データ消失、生成内容による不快感、または本サービスの利用不能によって生じた損害について、開発者は一切の責任を負いません。

4. 禁止事項

本サービスの利用にあたり、以下の行為を禁止します。

  • 生成された結果を用いて他者を誹謗中傷、差別、攻撃する行為。
  • 東方Projectの二次創作ガイドライン、および公序良俗に反する行為。
  • サーバーに過度な負荷をかける等の妨害行為。
  • その他、開発者が不適切と判断する行為。

5. データの取扱い

本サービスへの入力データは、物語生成のために Google Gemini API に送信されます。 「共有」機能を利用した場合、入力内容および生成結果はサーバー上に保存され、固有のURL（ID）を知る第三者が閲覧可能になります。

6. 著作権について

「東方Project」および作中キャラクター、世界観の著作権は、上海アリス幻樂団（ZUN様）に帰属します。 本サービス独自のスクリプトおよびUIデザインの著作権は開発者に帰属しますが、生成された物語の著作権についてはAIおよび各権利者のガイドラインに準じます。
